# Alliance Task Manager

Django-приложение для управления задачами: роли менеджер и работник, рейтинг, команды, навыки.

## Быстрый старт

```bash
cd alliance
python -m venv ../venv
..\venv\Scripts\activate   # Windows
pip install -r ../requirements.txt
copy ..\.env.example ..\.env
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте http://127.0.0.1:8000/

## Роли

- **Работник** — регистрация через `/accounts/register/` (роль по умолчанию).
- **Менеджер** — на той же странице: роль «Менеджер» и код из `MANAGER_REGISTRATION_CODE` в `.env`. Если переменная пустая — только через админку.

## Таймер рабочего времени

Работник включает таймер в шапке (клик по кружку с временем). Сессии сохраняются в БД; при выходе со страницы, закрытии вкладки или logout таймер останавливается автоматически.

Менеджер видит таблицу **«Рабочее время сотрудников»** на главной странице: кто сейчас working, длительность текущей сессии, итог за сегодня и за неделю.

## Просроченные задачи

Не обрабатываются при открытии страницы. Запускайте вручную или по cron:

```bash
python manage.py mark_overdue_tasks
```

## Структура

- `accounts/` — пользователи, навыки
- `tasks/` — задачи, команды, дашборды
